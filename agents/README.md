# マルチエージェント型 提案改善ワークフロー

このディレクトリには、提案を複数の視点から改善するための「エージェント定義」が入っています。

---

## ワークフロー全体像

```
┌─────────────────┐     ┌─────────────────┐
│  アジェンダ      │     │  ソリューション  │
│  エージェント    │     │  エージェント    │
│  (agenda-agent) │     │  (solution-agent)│
└────────┬────────┘     └────────┬────────┘
         │ A1〜A6の分析           │ S1〜S7の分析
         ▼                       ▼
    ┌────────────────────────────────────┐
    │   あなた（オーケストレーター）      │
    │   strategy-canvas.html で紐づけ    │
    └────────────────┬───────────────────┘
                     │ マッピング結果をエクスポート
                     ▼
    ┌────────────────────────────────────┐
    │   Claude（統合エージェント）        │
    │   FEEDBACK.md を読んでスライド更新  │
    └────────────────────────────────────┘
```

---

## 各エージェントの使い方

### ステップ1: エージェントに分析させる

**方法A: strategy-canvas.html のボタンから**
1. `strategy-canvas.html` を開く
2. 「📊 アジェンダ視点で分析」または「💡 ソリューション視点で分析」をクリック
3. 表示されたプロンプトをコピー
4. このチャット（またはClaudeの新しいチャット）に貼り付ける
5. Claudeの出力を `FEEDBACK.md` に貼り付けてコミット

**方法B: このファイルから直接プロンプトをコピー**
- `agenda-agent.md` の「プロンプト」セクションをコピー
- `solution-agent.md` の「プロンプト」セクションをコピー

### ステップ2: あなたが紐づけを判断する

`strategy-canvas.html` を開いて：
1. 左の「経営アジェンダ」カードをクリックして選択
2. 右の「ソリューション」カードをクリックして接続
3. 接続に優先度（高/中/低）とメモを追加
4. 「エクスポート」でマッピング結果をMarkdownにコピー

### ステップ3: Claudeに反映させる

コピーしたマッピングをこのチャットに貼り付けて：
```
上記のマッピングをスライドに反映してください。
優先度「高」の接続から順に実施してください。
```

## ファイル構成

| ファイル | 内容 |
|---------|------|
| `agenda-agent.md` | アジェンダエージェントの定義・プロンプト・出力テンプレート |
| `solution-agent.md` | ソリューションエージェントの定義・プロンプト・出力テンプレート |
| `README.md` | このファイル |

---

## 出力の保存先

各エージェントの分析結果は `FEEDBACK.md` に追記していきます。
フォーマット：

```markdown
## [日付] アジェンダエージェント分析結果
（Claudeの出力をここに貼り付け）

## [日付] ソリューションエージェント分析結果
（Claudeの出力をここに貼り付け）

## [日付] マッピング結果（戦略カンバス）
（strategy-canvas.htmlのエクスポート結果をここに貼り付け）
```
